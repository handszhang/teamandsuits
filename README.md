# 法律材料自动分类脚本

用于将散落的法律材料文件按规则自动分类归档到指定目录。

## 环境要求

- Windows 系统
- Python 3.7+
- 路径支持中文和长文件名

## 安装

1. 确保已安装 Python（可在命令行运行 `py --version` 验证）
2. 将 `classify.py` 和 `rules.json` 放在同一目录
3. 无需额外安装依赖

## 使用方法

### 基本用法

```bash
cd /d D:\你的文件夹路径
py classify.py
```

### 参数说明

| 参数 | 说明 | 示例 |
|------|------|------|
| 无参数 | dry-run 模式，只预览不复制 | `py classify.py` |
| `--apply` | 执行真实复制 | `py classify.py --apply` |
| `--case <案件名>` | 限定只处理某个案件 | `py classify.py --case 艾辰硕` |
| `--source <路径>` | 指定源目录 | `py classify.py --source D:\材料` |

### 三步交互流程

```
第1步：扫描统计
  → 显示扫描到的文件数量、类型分布
  → 按回车继续

第2步：分类预览
  → 显示每个文件的分类结果
  → 可调整归类或保持原样
  → 输入 c 确认继续

第3步：确认执行
  → 显示待复制文件数量
  → 输入 y 执行 / n 退出
```

### 交互调整说明

| 输入 | 作用 |
|------|------|
| `c` | 确认当前分类，进入下一步 |
| `q` | 退出程序 |
| `s3` | 保持原样，不移动（如 s+序号） |
| `3 律师函` | 把序号3的文件改分为"律师函" |

## rules.json 规则维护

### 规则格式

```json
{
  "categories": [
    {"name": "分类名", "keywords": ["关键词1", "关键词2"], "target_path": "目标路径"}
  ],
  "default_category": {
    "name": "默认分类名",
    "target_path": "默认目标路径",
    "description": "说明"
  }
}
```

### 添加新规则

在 `categories` 数组中添加：

```json
{"name": "新分类", "keywords": ["关键词"], "target_path": "归档/路径"}
```

### 关键词说明

- 关键词按顺序匹配，匹配到第一个即生效
- 关键词支持任意中文、英文、数字组合
- 建议用能代表文件类型的高频词汇

## Windows 注意事项

1. **长路径支持**：脚本已处理 Windows 长路径（\\?\ 前缀）
2. **中文路径**：完全支持中文文件夹名和文件名
3. **编码**：所有文件操作使用 UTF-8 编码
4. **运行方式**：
   - 推荐用 `py classify.py`（自动使用已安装的 Python）
   - 也可用 `python classify.py`

## 常见问题

### Q: 为什么有些文件没匹配到任何规则？

A: 检查 rules.json 里是否添加了相关关键词，或文件确实属于"待整理"类别。

### Q: 复制时出现重名文件会怎样？

A: 会自动在文件名后加序号，如 `借款合同_1.pdf`，不影响原文件。

### Q: 如何只预览不复制？

A: 不加 `--apply` 参数，默认是 dry-run 模式。

### Q: 源文件会被移动吗？

A: 不会。脚本只复制文件到目标目录，源文件保持不动。

### Q: 可以指定只处理某个案件吗？

A: 可以，用 `--case 案件名` 参数，如 `py classify.py --case 艾辰硕`

## 文件说明

| 文件 | 作用 |
|------|------|
| classify.py | 主程序脚本 |
| rules.json | 分类规则配置 |
| classification_report.md | 分类报告（运行后生成） |
| 归档/ | 分类后的目标目录 |

## 技术细节

- 只扫描文件，不扫描空目录
- 跳过归档目录本身，避免循环
- 默认排除：.py、.json、.md 类型的脚本和配置文件
- 目标目录不存在会自动创建
